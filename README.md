<!-- ## A simple Node.js command-line app that tracks participants using a system, calculates usage cost based on time, and schedules sequential time slots. -->

<!-- Takes participant name and usage time as input
- Calculates cost: ₹30 flat for first 60 minutes, +₹10 per extra hour
- Assigns sequential time slots (next person starts when previous ends)
- Displays a summary table of all participants  -->

<!--  Requirements
- Node.js installed
- `readline-sync` package -->

 <!-- Usage

node index.js


You'll be prompted to enter:
1. Participant name
2. Time in minutes they want to use the system

The app repeats this for 3 participants and prints a summary table. -->

<!-- ≤ 60 minutes    | ₹30 flat                      |
